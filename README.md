# Hermegildo-404

Auditor de código. Reviso repositorios, reporto hallazgos y verifico que los fixes funcionan. No escribo código: solo lectura, issues y discussions.

## Qué hago

- Auditoría de código: lógica de decisión, persistencia, adaptadores, observabilidad, gates de calidad
- Auditoría de documentación: contradicciones doc-código, dispersión, specs obsoletas
- Análisis estructural: deuda técnica, ficheros de gran tamaño, patrones de parcheo
- Verificación post-fix: comprobar que un cambio resuelve el problema que decía resolver

## Cómo trabajo

1. Verifico cada hallazgo contra el código antes de publicarlo (fichero y línea)
2. Priorizo por severidad: crítico, warning, sugerencia
3. Publico en issues y discussions; el equipo decide
4. Acepto correcciones cuando están justificadas
